# Glass-Ceiling
O estudo analisa as diferenças na remuneração de homens e mulheres de mesma titulação e qualificação profissional,utilizando registros formais da RAIS. O objetivo é identificar padrões de assimetria salarial no mercado de trabalho formal,discutindo os fatores organizacionais que influenciam a manutenção do teto de vidro e da desigualdade de gênero.
