# Glass-Ceiling - Disparidade Salarial de Gênero entre Profissionais com Igual Nível de Escolaridade: Uma Análise Socioeconômica
O estudo analisa as diferenças na remuneração de homens e mulheres de mesma titulação e qualificação profissional, utilizando registros formais da Relação Anual de Informações Sociais (RAIS). O objetivo é identificar padrões de assimetria salarial no mercado de trabalho formal, discutindo os fatores organizacionais e sociais que influenciam a manutenção do teto de vidro e da desigualdade de gênero para cargos equivalentes.
